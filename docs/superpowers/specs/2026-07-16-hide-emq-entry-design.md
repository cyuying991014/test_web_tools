# 暂时隐藏 EMQ 设备影子入口

## 背景

EMQ 设备影子依赖本地环境调用，当前不适合作为前端公开入口展示。现有功能实现需要保留，便于后续恢复。

## 目标

- 顶部导航不再显示“EMQ 设备影子”入口。
- 顶部副标题不再展示“设备影子”文案。
- 常用测试工具页面保持现有默认展示和交互。

## 实现范围

仅修改 `index.html`：

1. 删除 `data-site-view="emq"` 的顶部 Tab 按钮。
2. 将顶部副标题从“测试工具箱 · 设备影子”调整为“测试工具箱”。

保留以下内容，不做删除或重构：

- `#page-emq` 页面 DOM。
- `src/emqApp.js` 及 `src/emqShadowApi.js` 等 EMQ 实现。
- `src/main.js` 中的 EMQ 初始化调用。
- `vite.config.js` 中的本地代理配置。

## 方案比较

- 直接移除入口标记：改动最小，公开页面中不存在可点击入口，后续可通过恢复两处 HTML 重新开放。采用此方案。
- CSS 隐藏：恢复方便，但无意义节点仍存在于 DOM，不够干净。
- 环境变量控制：适用于长期区分部署环境，但当前只是暂时下线，增加开关属于过度设计。

## 验证

1. 运行 `npm run build`，确认生产构建通过。
2. 检查构建产物首页，不包含“EMQ 设备影子”入口和“测试工具箱 · 设备影子”副标题。
3. 检查源码，确认 EMQ 页面、初始化和代理实现仍保留。

## 风险与恢复

该修改只影响可见入口，不阻止用户通过开发者工具手工操作隐藏页面，也不移除相关代码。恢复时重新添加顶部 Tab，并恢复副标题文案即可。
