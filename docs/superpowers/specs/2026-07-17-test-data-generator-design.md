# 测试数据生成器设计

## 目标

在现有测试工具聚合平台顶部增加独立一级 Tab“测试数据生成”，提供面向软件测试工程师的浏览器本地数据生成能力。

首版同时满足两类使用方式：临时获取单一测试值，以及配置多个字段后批量生成接口、数据库和自动化测试所需的数据。生成过程、模板存储和文件导出均在浏览器本地完成，不依赖后端、账号或云端服务。

## 已确认的产品边界

- “测试数据生成”与“常用测试工具”作为并列的顶部一级 Tab。
- 首版采用“字段库 + 数据模型设计器”，附带少量内置场景模板。
- 地域范围为中国大陆数据与国际通用数据，不覆盖多国家证件、电话和地址规则。
- 同时支持单字段快速生成和多字段组合生成。
- 支持有效、边界、无效和混合数据。
- 支持基础字段关联和固定随机种子复现。
- 模板只保存在当前浏览器，并支持配置文件导入和导出。
- 单次生成 1～10,000 条；页面最多预览前 100 条。
- 支持复制、JSON、CSV，以及 MySQL、PostgreSQL、SQLite 三种 SQL `INSERT` 导出。
- 所有身份、账号、设备和业务号码均为按规则合成的测试数据，不使用真实个人数据集。

## 本次不包含

- 文件、图片、音频、视频及超大文件样本生成。
- 美国、英国、日本等国家或地区的证件、电话和地址规则。
- 根据任意正则表达式反向生成字符串。
- 用户账号、权限、云端同步或团队共享。
- 连接数据库并直接执行 SQL。
- `CREATE TABLE`、`UPDATE`、`DELETE` 等 SQL 生成。
- 真实 JWT、登录凭据、签名 Token 或可用于真实系统认证的密钥生成。
- 读取真实个人信息作为生成来源。

## 页面结构

### 顶部入口

在现有顶部导航中新增“测试数据生成”一级 Tab。切换 Tab 时保留当前页面内尚未刷新的字段配置；切回“常用测试工具”时不影响原有工具状态和行为。

### 快速生成

快速生成用于临时获取某一种测试数据。

操作流程：

1. 通过分类或搜索选择数据类型。
2. 配置生成数量、数据模式和该类型的专属规则。
3. 可选填写随机种子。
4. 点击“生成数据”。
5. 查看、复制、重新生成或清空结果。

例如，手机号生成器可以配置号段范围、是否允许重复、有效或无效模式以及生成数量。

### 组合生成

组合生成用于构造接口请求、数据库记录和批量测试数据。

一个数据模型由多个有序字段组成。每个字段包含：

- 字段名。
- 数据类型。
- 有效、边界、无效或混合模式。
- 类型专属规则。
- 是否唯一。
- 空值比例。
- 重复值比例。
- 固定值或默认值。
- 与其他字段的关联关系。
- 是否附加测试元信息。

模型公共配置包含：

- 生成数量，范围为 1～10,000。
- 随机种子。
- 输出字段顺序。
- JSON 输出结构。
- SQL 方言、表名和批次大小。
- 有效、边界和无效数据的分布比例。

基本流程：

1. 新建模型或加载模板。
2. 添加、排序并配置字段。
3. 校验字段规则和关联关系。
4. 先生成少量预览数据。
5. 确认后生成完整批次。
6. 复制结果或导出 JSON、CSV、SQL。

### 模板管理

首版提供以下内置模板：

- 用户注册数据。
- 登录账号数据。
- 订单基础数据。
- 接口请求参数。
- 设备基础数据。

用户可以将当前模型保存为本地模板，也可以重命名、复制、删除、导出和导入模板。内置模板不可直接覆盖；用户修改后另存为本地模板。

模板只保存字段、规则、关联关系、输出配置和可选随机种子，不保存已经生成的数据。

### 结果区

- 页面以表格形式最多预览前 100 条，并明确显示完整生成数量。
- 支持横向滚动和字段值单独复制。
- 支持复制当前单元格、当前行、当前列、当前预览和全部结果。
- 当前行按 JSON 对象复制。
- 导出使用完整结果，不受 100 条预览限制。
- 修改配置后保留旧结果，但必须标记“结果已过期，请重新生成”。
- 重新生成前保留全部配置。

## 首版字段库

### 人员与身份

- 中文姓名、英文姓名。
- 性别、年龄、出生日期。
- 中国大陆身份证号，支持指定地区、出生日期、性别和合法校验位。
- 中国大陆手机号、座机号。
- Email。
- 省、市、区县、详细地址。
- 邮政编码。

身份证等数据由规则随机合成。页面必须说明：格式和校验位合法不代表数据对应真实个人，随机结果在理论上可能与现实号码偶合。

### 账号与认证

- 用户名、昵称。
- 密码，支持长度、大小写、数字和特殊字符规则。
- 数字验证码、字母数字验证码。
- Token 风格随机字符串。
- API Key 风格随机字符串。

Token 和 API Key 只生成指定格式的随机字符串，不实现真实系统的签名或认证算法。

### 数字与基础类型

- 整数、正整数、负整数。
- 小数，支持范围、精度和小数位。
- 布尔值。
- `null`、空字符串和空格字符串。
- 枚举值，支持随机、顺序和权重选择。
- 自增序号，支持起始值和步长。
- 固定值。

### 文本数据

- 中文、英文、数字和混合随机文本。
- 固定长度或长度区间。
- 前缀和后缀。
- 单行和多行文本。
- 特殊字符和 Emoji。
- 超长文本。
- 从用户提供的候选词列表中抽取。

### 日期与时间

- 日期、日期时间、Unix 秒时间戳和毫秒时间戳。
- 指定时间范围。
- 过去或未来若干天。
- 当前时间附近随机偏移。
- 工作日和周末。
- 开始时间和结束时间关联。
- 自定义输出格式和时区，默认提供北京时间。

### 标识符与业务编号

- UUID v4。
- 纯数字 ID 和自增 ID。
- 订单号、流水号和批次号。
- Trace ID 和 Request ID。
- 由前缀、日期片段、序号和随机片段组成的自定义业务编号。
- 设备 SN 和 IMEI 风格号码。
- 符合 Luhn 校验规则的中国大陆银行卡号格式。

这些号码只用于格式与校验逻辑测试，不声明属于真实机构、账户或设备。

### 网络与设备

- IPv4、IPv6。
- 内网 IPv4、公网 IPv4、回环地址和边界地址。
- MAC 地址。
- 域名和主机名。
- URL。
- 端口号。
- User-Agent 预设。
- 经纬度。
- 软件版本号和固件版本号。

### 测试专用异常与边界数据

各字段按自身规则提供适用的异常和边界能力：

- 最小值、最大值和零值。
- 低于下限和高于上限。
- 空值和缺失值。
- 长度不足和长度超限。
- 非法字符和格式错误。
- 校验位错误。
- 重复值。
- 类型错误。

## 生成规则

### 数据模式

每个字段支持四种模式：

- **有效数据**：全部满足字段规则。
- **边界数据**：优先生成最小值、最大值、长度边界、空值边界等。
- **无效数据**：按用户选择破坏一项或多项规则。
- **混合数据**：配置有效、边界和无效数据比例，三者合计必须为 100%。

页面预览需要标记异常数据类型和原因。标记默认不进入业务字段；用户可以选择额外导出 `_testMeta`。

### 通用规则

适用字段可以配置：

- 必填或允许空值。
- 固定长度或长度范围。
- 唯一值约束。
- 重复值比例。
- 固定值。
- 候选值列表。
- 前缀和后缀。
- 自增序号和步长。
- 候选值出现权重。

规则冲突时禁止生成，并定位到具体字段。例如，“全部唯一”和“大于 0% 的重复值比例”不能同时生效。

### 字段关联

首版通过可视化配置提供以下关联，不要求用户编写表达式：

- 身份证派生出生日期、年龄、性别和地区。
- 出生日期派生年龄。
- 省份约束城市，城市约束区县和邮政编码。
- 开始时间约束结束时间，并配置最小和最大间隔。
- 姓名派生用户名、昵称或 Email 前缀。
- 基础金额乘以数量生成总金额，并配置小数位和舍入方式。
- 日期、前缀、序号和随机片段组合成订单号、流水号或批次号。
- 任意字段值作为另一个字段的前缀或后缀。

源字段被删除、改名或改为不兼容类型时，关联必须标记失效并阻止生成。字段依赖形成循环时，页面需要展示循环路径。

### 随机种子

- 不填写种子时，每次生成不同结果。
- 填写种子时，相同模板、配置、数量、生成器版本和种子必须得到完全相同的结果。
- 修改任意生成规则后，即使种子相同，也允许结果变化。
- 普通字段、异常分布、候选值选择和关联字段均使用统一随机源。
- 随机算法带版本号；模板保存算法版本。

## 输出与导出

### JSON

- 支持对象数组。
- 生成数量为 1 时可选单个对象。
- 支持可视化配置嵌套对象结构。
- 支持美化和压缩格式。
- 使用 UTF-8，文件扩展名为 `.json`。

### CSV

- 第一行为字段名，并保持字段配置顺序。
- 按 CSV 规则处理逗号、双引号和换行。
- 默认使用 UTF-8 BOM，保证中文内容在常见 Excel 环境中正常显示。
- 嵌套对象和数组转换为 JSON 字符串写入单元格。
- `null` 默认输出为空单元格，也可配置为文本 `null`。
- 对以 `=`、`+`、`-`、`@` 开头的文本进行公式注入防护。

### SQL `INSERT`

支持 MySQL、PostgreSQL 和 SQLite。导出时配置：

- 数据库方言。
- 表名。
- 每批语句包含的行数。
- 是否包裹事务语句。

导出器需要按所选方言处理表名、字段名、字符串、布尔值、日期和 `NULL`。默认生成批量 `INSERT`。嵌套对象和数组按 JSON 字符串写入，用户负责确认目标字段类型兼容。

SQL 只用于复制或下载 `.sql` 文件，不连接数据库执行。

### 测试元信息

用户可以选择在导出结果中附加异常数据说明：

- JSON 使用 `_testMeta` 对象。
- CSV 增加 `_testMode` 和 `_testReason` 列。
- SQL 默认不附加；只有用户明确启用并配置对应字段后才输出。

## 配置校验与异常处理

### 错误

以下问题必须阻止生成，并定位到具体字段或配置项：

- 字段名为空或重复。
- 数量不是 1～10,000 的整数。
- 范围上下限颠倒。
- 长度、比例或权重不合法。
- 唯一与重复规则冲突。
- 关联字段不存在或类型不兼容。
- 字段关联形成循环。
- 混合模式比例合计不为 100%。
- SQL 表名、字段名或批次大小不合法。

### 警告

生成数量较大、无效数据比例过高、候选空间不足以满足唯一约束等情况可以展示警告；如果仍有可能完成生成，允许用户确认后继续。

### 模板导入

- 校验文件格式、模板版本、字段类型、规则和关联关系。
- 导入内容先进入临时配置，校验成功后才能新增或覆盖本地模板。
- 损坏、不兼容或包含未知可执行内容的文件不得影响当前配置。
- 不使用 `eval` 或动态脚本执行模板内容。

### 运行状态

- 生成期间显示进度并禁止重复启动相同任务。
- 支持取消当前任务。
- 失败或取消后保留用户配置。
- 浏览器内存不足、复制失败或导出失败时给出明确中文提示。
- 大批量复制失败时引导用户使用文件导出。

## 隐私与数据集

- 所有生成、预览、复制、模板处理和文件导出均在当前浏览器完成。
- 不上传配置、模板或生成结果。
- 不内置真实身份证、银行卡、手机号、地址或账号数据集。
- 页面持续显示“仅供软件测试使用”的说明。
- 中国省、市、区县等数据作为带版本号的静态资源随前端发布。
- 地址只按行政区划和随机文本组合，不映射真实住户。
- 静态数据集更新通过发布新版本完成，不依赖运行时接口。

## 架构与组件

### 页面层

在 `index.html` 中增加顶部 Tab 和独立页面容器。数据生成页面沿用现有视觉语言，但拥有自己的快速生成、组合生成和模板管理区域。

### 交互层

新增独立的 `dataGeneratorApp.js`，负责：

- Tab 内页面初始化。
- 字段选择、配置和排序。
- 模板管理。
- 校验错误和任务状态展示。
- 预览表格、复制和导出操作。

主入口只负责初始化和顶层 Tab 切换，不承载字段生成逻辑。

### 核心模块

核心能力按职责拆分：

- `catalog/`：字段分类、名称、说明、默认规则和配置定义。
- `generators/`：各类型字段生成器。
- `rules/`：有效、边界、无效和混合模式。
- `relations/`：字段依赖、拓扑排序和关联计算。
- `random/`：带版本的确定性随机算法。
- `exporters/`：JSON、CSV和三种 SQL 方言。
- `templateStore.js`：本地模板保存、迁移、导入和导出。
- `datasets/`：行政区划、姓氏、常用名和号段等静态数据。
- `dataGeneratorWorker.js`：批量生成、进度和取消。

每个字段生成器遵循统一能力边界：校验配置、生成有效值、生成边界值、生成无效值、返回异常原因。生成器不直接访问 DOM 或本地存储。

### 数据流

1. 页面收集并规范化配置。
2. 校验字段、模式、比例和输出设置。
3. 建立字段依赖图并检查循环。
4. 根据随机种子和算法版本初始化统一随机源。
5. Web Worker 按字段依赖顺序逐行生成数据。
6. 应用唯一、重复、空值和异常比例。
7. 生成可选测试元信息。
8. 返回进度、前 100 条预览及完整结果。
9. 页面将同一份完整结果交给复制或导出器。

### 性能与状态边界

- 组合数据统一在 Web Worker 中生成，避免阻塞页面。
- 快速生成复用相同核心生成器，避免两种入口产生不同规则。
- 当前配置和生成结果保存在页面内存。
- 用户主动保存后，模板写入 `localStorage`。
- 页面刷新后恢复已保存模板，但不恢复生成结果。
- 不配置种子时，由浏览器安全随机源产生初始种子；具体字段不得直接调用 `Math.random()`。

## 验收标准

1. 顶部出现独立“测试数据生成”Tab，切换不影响原有工具。
2. 快速生成、组合生成和模板管理均可正常进入和操作。
3. 首版八类字段均能生成有效数据，并具有对应配置校验。
4. 身份证、银行卡、IMEI 等带校验规则的数据能够生成正确校验位，也能按无效模式故意破坏校验位。
5. 有效、边界、无效和混合模式均能正确工作，并提供异常原因。
6. 相同配置、数量、生成器版本和随机种子得到完全一致的结果。
7. 身份证与出生日期、年龄、性别、地区等关联字段保持一致。
8. 时间、金额、地址和组合编号关联满足已配置约束。
9. 唯一、重复、空值和权重规则按配置执行；冲突规则阻止生成。
10. 字段关联失效或形成循环时禁止生成，并显示具体原因。
11. 单次支持 1～10,000 条；页面最多渲染前 100 条，完整导出条数正确。
12. JSON 支持对象数组、单对象、嵌套对象、美化和压缩。
13. CSV 正确处理中文、逗号、双引号、换行、`null`和公式注入风险。
14. MySQL、PostgreSQL、SQLite 导出正确处理标识符、字符串、布尔值、日期和 `NULL`。
15. 保存的模板刷新页面后仍可使用，生成结果刷新后清空。
16. 损坏或不兼容的模板不能破坏当前配置和已有模板。
17. 生成、取消、失败、复制和导出状态均有明确中文反馈。
18. 所有处理在浏览器本地完成，首次联网缓存后可按现有 PWA 机制离线使用。

## 验证

### 生成器专项验证

每一种字段生成器至少覆盖：

- 最小配置。
- 典型有效配置。
- 上下边界。
- 非法配置。
- 固定种子复现。
- 批量唯一性。
- 无效数据原因标记。

带校验位的数据需要使用独立校验函数验证生成结果，不能只断言字符串长度或正则格式。

### 规则与关联验证

- 四种数据模式。
- 混合模式比例边界。
- 唯一、重复、空值和权重。
- 身份、地址、时间、金额和组合编号关联。
- 关联字段被删除、改名或改类型。
- 循环依赖检测。
- 相同随机种子跨重复执行保持稳定。

### 导出验证

- JSON 单对象、对象数组、嵌套结构、美化和压缩。
- CSV 中文、引号、逗号、换行、空值、嵌套值和公式注入防护。
- MySQL、PostgreSQL、SQLite 标识符和各类型值的转义。
- SQL 批次拆分和可选事务语句。
- 10,000 条导出的条数和字段顺序。

### 页面与性能验证
